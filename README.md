# Bourbon Guide

An unofficial, map-first guide to Kentucky's bourbon distilleries. Static Next.js site, config-driven from
`src/data/map.json`, records in `src/data/stops.json`. Built by Peachy Kean DevOps, LLC. 21+.

```bash
npm install
npm run dev          # http://localhost:3000
npm run check:data
npm run build        # static export to out/
```
